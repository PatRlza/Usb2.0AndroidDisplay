# ДопЭкран (UsbAndroidDisplay)

Приложение для Android, которое превращает **телевизор на Android TV во второй экран для телефона или планшета по USB-кабелю**.
Игра или приложение запускается на *виртуальном дисплее* 16:9, поэтому на ТВ нет чёрных полос (даже если у телефона экран 20:9),
а физический экран телефона можно выключить или использовать как тачпад.

> Статус: **экспериментальный проект**. Основной сценарий проверен на связке POCO F3 (Snapdragon 870) + Xiaomi Mi TV (Android 11, USB 2.0).
> Часть функций добавлена позже и проверена не на всех устройствах — см. [«Что работает»](#что-работает).

## Зачем

Многие телевизоры и планшеты Xiaomi не умеют выводить картинку по USB-C → HDMI. Wi-Fi-трансляция даёт заметную задержку.
Идея проекта: телевизор сам становится USB-хостом, подключается к телефону по ADB и принимает от него сжатое H.264-видео,
которое он декодирует аппаратно. Битрейта 8–14 Мбит/с с запасом хватает даже для USB 2.0 (480 Мбит/с).

## Возможности

- Второй экран по **USB** (H.264, аппаратное кодирование на телефоне и декодирование на ТВ), цель — минимальная задержка.
- **Виртуальный дисплей 16:9** (720p / 1080p / 1440p, 30 или 60 к/с) — запуск конкретного приложения без чёрных полос.
- Один APK для ТВ и телефона: на ТВ открываются плитки приложений, на телефоне — режим тачпада. ТВ **сам устанавливает приложение на телефон по кабелю**.
- Плитки приложений с телефона по категориям (игры, видео, общение, приложения, система), иконки, избранное, запоминание вкладки, счётчик открытых приложений и кнопка «закрыть все».
- **Тачпад** на телефоне (чёрный экран с минимальной яркостью): курсор, клик, перетаскивание, прокрутка, «Назад».
- Управление **пультом ТВ**: курсор, клик, перетаскивание, «Назад», панель статистики.
- **Звук** на ТВ (несжатый PCM 48 кГц, низкая задержка).
- **Адаптивный битрейт** между запусками (по результатам прошлых игр: кадры в секунду, заторы, лишняя задержка).
- Режимы задержки «Баланс» / «Минимум», режим производительности на телефоне, выключение экрана телефона.
- Диагностика: статистика потока, замер «Отклик на касание», тесты USB/ADB, настройка размера ADB-пакета.

## Как это работает

```
Телефон                                              Телевизор (Android TV)
┌──────────────────────────────┐   USB-кабель   ┌────────────────────────────────┐
│ scrcpy-server (запускается   │ ─────────────▶ │ собственный ADB-клиент (USB    │
│ с ТВ через `app_process`)    │   ADB / USB    │ host, без adb.exe и ПК)        │
│  VirtualDisplay → MediaCodec │                │  → MediaCodec (декодер)        │
│  H.264 + звук PCM            │ ◀───────────── │  → SurfaceView                 │
│ приложение «ДопЭкран»        │  управление    │  → курсор, пульт               │
│  (режим тачпада)             │                │                                │
└──────────────────────────────┘                └────────────────────────────────┘
```

1. ТВ находит телефон среди USB-устройств, получает доступ и проходит авторизацию ADB (свой RSA-ключ, подтверждение на телефоне).
2. ТВ загружает `scrcpy-server` на телефон и запускает его командой `app_process`. Сервер создаёт виртуальный дисплей `new_display=1920x1080`
   и отдаёт три потока: видео, звук, управление.
3. ТВ запускает выбранное приложение на этом дисплее (`am start --display <id>`), декодирует поток и показывает его на весь экран.
4. Ввод идёт обратно: курсор с пульта или тачпада превращается в касания виртуального дисплея через канал управления scrcpy.
5. Тачпад: приложение на телефоне слушает абстрактный сокет, ТВ подключается к нему через ADB (по тому же кабелю).

Подробности протоколов, результаты тестов и журнал решений — в [`PROJECT.md`](PROJECT.md).

## Требования

| | |
|---|---|
| ТВ / приставка | Android TV / Android 8.0+ (minSdk 26), поддержка **USB host** и аппаратный H.264-декодер |
| Телефон | Android 10+ с «Отладкой по USB»; для виртуального дисплея и звука рекомендуется Android 11+ |
| Кабель | Данные, а не только зарядка (USB-C ↔ USB-A/USB-C, подходящий порт ТВ) |
| Для сборки | Android Studio (Kotlin, Gradle), SDK Platform 34 |

Звук и виртуальный дисплей зависят от версии Android и прошивки телефона.

## Сборка

1. Клонируйте репозиторий и откройте папку `tester-tv` в Android Studio (**Open**). Gradle Sync подтянет всё необходимое.
2. Файл `app/src/main/assets/scrcpy-server` — это сервер **scrcpy 5.0.1**. Он должен совпадать с константой `ScrcpySession.SERVER_VERSION`.
   Если файла нет, скачайте релиз [scrcpy v5.0.1](https://github.com/Genymobile/scrcpy/releases/tag/v5.0.1) и возьмите из него `scrcpy-server`
   (без расширения), положив в `tester-tv/app/src/main/assets/`.
3. **Build → Build APK(s)** (`app/build/outputs/apk/debug/app-debug.apk`).
4. Установите APK на ТВ (флешка, `adb install` по Wi-Fi или запуск из Studio).

Имя пакета сейчас временное: `com.example.usbdisplay.tester`. Перед публикацией в магазине его нужно сменить.

## Использование

1. На телефоне включите **«Отладку по USB»** (на Xiaomi/POCO ещё **«Установка через USB»** и «Отладка по USB (настройки безопасности)»).
2. Подключите телефон к ТВ кабелем. На ТВ откройте «ДопЭкран» и разрешите доступ к USB-устройству, затем подтвердите отладку на телефоне
   («Всегда разрешать с этого компьютера»).
3. ТВ прочитает список приложений и сам установит «ДопЭкран» на телефон (потребуется разблокированный телефон).
4. Выберите плитку приложения. В карточке запуска настройте режимы и нажмите **«▶ Запустить»**.
5. Если выбран «Тачпад на телефоне» — приложение на телефоне откроется само: водите пальцем по чёрному экрану.

### Управление

| Действие | Пульт ТВ | Тачпад на телефоне |
|---|---|---|
| Двигать курсор | стрелки (при удержании курсор разгоняется) | один палец |
| Клик | OK | короткое касание |
| Перетаскивание | долгое OK, стрелками, OK — отпустить | удержание ≈ 0,45 с и движение |
| Прокрутка | — | два пальца |
| Назад (в приложении) | — | быстрое касание тремя пальцами |
| Показать/скрыть панель статистики | «Назад» (короткое) | — |
| Выход из трансляции | долгое «Назад» | — |

Геймпад, подключённый к телефону, остаётся на телефоне и в ТВ не пересылается.

### Карточка запуска

- **Тачпад на телефоне** / **Экран телефона выкл.** — взаимоисключающие (можно выключить оба): сенсор нужен для тачпада.
- **Производительность** — закрывает фоновые процессы на телефоне, включает игровой режим «Производительность» (если прошивка поддерживает) и просит 120 Гц.
  Что реально сработало, пишется в журнал на экране трансляции.
- **Звук на ТВ**, **Адаптивный битрейт** (или ручной выбор), **Задержка: Баланс / Минимум**, **Экран** (720p/1080p/1440p), **Кадры** (30/60), **Пакет ADB**.

## Что работает

| Функция | Статус |
|---|---|
| USB host на ТВ, ADB по USB (CNXN/AUTH/OPEN/WRTE, sync push) | проверено |
| Запуск scrcpy-server, видео H.264 на ТВ | проверено |
| Виртуальный дисплей 16:9, запуск приложений, 60 к/с | проверено |
| Курсор и клики с пульта, плитки приложений, звук | проверено |
| Тачпад на телефоне, автоустановка на телефон, иконки | реализовано, проверено частично |
| Адаптивный битрейт, режим «Минимум», режим производительности | реализовано, проверяется |
| Геймпад → игра на виртуальном дисплее | не решено (ввод с геймпада телефона идёт на основной дисплей) |

Ограничения:
- Задержка зависит и от самого ТВ (обработка картинки, отсутствие игрового режима); канал USB 2.0 для 1080p60 достаточен, но не идеален.
- Телефоны с ограничениями ADB (особенно MIUI/HyperOS) могут требовать дополнительных разрешений для установки и запуска активностей.
- Приложения с `FLAG_SECURE` (банки, часть видеосервисов) на виртуальном дисплее показываются чёрными.
- Тачпад при выключенном экране телефона не гарантирован (на разных телефонах сенсор ведёт себя по-разному).

## Структура проекта

```
tester-tv/app/src/main/java/com/example/usbdisplay/
├── adb/       собственный ADB-клиент поверх USB host (сообщения, ключи, потоки, sync, замок USB)
├── scrcpy/    запуск сервера, видео/звук/управление, декодер, пробы
├── apps/      список приложений телефона, иконки, автоустановка, адаптивный битрейт, режим производительности
├── pad/       протокол и канал тачпада «телефон → ТВ»
└── tester/    экраны: LauncherActivity (плитки), PlayerActivity (трансляция), PadActivity (тачпад),
               IconActivity (иконки для ТВ), MainActivity (диагностика)
```

## Дорожная карта
